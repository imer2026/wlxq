# 合作主流程 TODO

本文档只维护“寻找合作 → 以 helper 身份进入 → 培养主 C → 选择技能 → 结算 → 下一局”的端到端待办。已确认规则见 [游戏规则知识库](../game-rules.md)，目标状态迁移见 [自动化执行流程](../automation-flow.md)。

当前代码已经串起完整状态机，且准备、返回、技能等部分模板已经存在；正式棋盘识别已经切换为 ONNX 格子分类模型。首页识别、部分界面素材和实机标定仍未完成，因此仍不能声称真实游戏环境下完整一局可用。招募入口、点赞和领取宝箱已经确认采用“点击成功即推进”，不增加动作后识别门禁。

以下 P0 项必须在能够正常运行微信小游戏、且显示器分辨率有对应模板包的 Windows 电脑上完成；离线开发机上的单元测试不能替代这些实机验证。
